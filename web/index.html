qmk-link 배열 마법사

KLE 로 그린 배열의 각 자리에 실제로 그 키가 보내는 HID usage 를 채운다. 브라우저 키 이벤트가 아니라 보드에서 직접 읽으므로 F13~F24 나 한/영 같은 키도 그대로 잡힌다.

★ VIA / Vial 을 쓰기 전에 [연결 끊기] 를 누른다. 같은 raw HID 를 쓰기 때문에, 이 페이지가 물고 있으면 저쪽이 장치를 못 알아본다. (탭을 옮기면 자동으로 멈추지만, 확실하게 하려면 끊는다)

연결 안 됨
또는 keyboard-layout-editor.com 에서 배열을 그리고 Raw data 를 그대로 붙여넣는다. 범례는 아무거나 좋다.

못 누르는 키(Fn 조합 등)는 자리를 클릭하고 이름으로 직접 넣는다 — LNG1 INT3 F13 MUTE …
앞의 둘은 VIA / Vial 에 바로 넣는다. layout-kle.json 은 저장소의 gen_keymap.py 입력이다.
